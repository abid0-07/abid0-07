### 🚀 Featured Security & Engineering Projects

- **🔍 Data Leakage Prevention (DLP) & Threat Detection Lab** *(Ongoing)*  
  Architected a segmented multi-VM enterprise environment using **Wazuh SIEM**, **Suricata IDS**, and custom `iptables` routing. Authored custom PCRE/regex Suricata rules and File Integrity Monitoring (FIM) alerts to detect PII exfiltration and insider threats.
- **🕵️ Insider Threat & Data Exfiltration Forensic Investigation**  
  Conducted a dead-box forensic investigation on a Windows disk image using **Autopsy**, correlating Registry hives, LNK shortcuts, USB histories, and OST emails to trace multi-channel IP theft and anti-forensic wiping.
- **⚔️ Adversary Emulation & SIEM Detection Lab**  
  Built a purple-team lab integrating **Splunk Enterprise** and **Sysmon** on Windows Server 2019. Executed **Atomic Red Team** scenarios (MITRE ATT&CK) and engineered behavioral SPL correlation rules for process creation, LSASS dumping, and registry modifications.
- **🛡️ Endpoint & Network Intrusion Detection Labs**  
  Engineered custom **Wazuh** XML rules (`local_rules.xml`) for DLL injection/ClickFix malware and **Suricata** signatures shipped via **ELK Stack** to detect RedLine Stealer C2 beaconing and SYN floods.
- **💥 Offensive Security & Vulnerability Assessment Lab**  
  Executed full-lifecycle penetration testing and vulnerability assessments across segmented targets using **Kali Linux, Metasploit, Nmap, Burp Suite, Nessus, and Acunetix**, covering BlueKeep (CVE-2019-0708), SQLi, and privilege escalation.
